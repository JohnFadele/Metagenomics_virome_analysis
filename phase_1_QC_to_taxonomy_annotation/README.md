**Phase 1: Read Quality Control, Host Depletion and Taxonomic Profiling**

**Overview**

This phase processes paired-end FASTQ sequencing data through quality control, adapter trimming, sequential host depletion, taxonomic classification and species-level abundance estimation. It uses fastp for read filtering, Bowtie2 for host read removal, Kraken2 for taxonomic classification and Bracken for abundance re-estimation. A supplementary Python script annotates Bracken outputs using NCBI taxonomy, optionally removes Homo sapiens entries, recalculates relative abundance fractions using non-host reads and combines individual sample results into a consolidated dataset.

**Scripts**

step_1_QC_bracken_pipeline.sh:__ Performs FASTQ renaming, quality control, host depletion, Kraken2 classification and Bracken abundance estimation.

step_2_annotation_and_combination.py:__ Performs taxonomic annotation, optional human-read filtering, relative abundance recalculation and sample-level data consolidation.

**Requirements**

_Software:_ fastp, Bowtie2, Kraken2, Bracken, jq and Python 3.

_Reference resources:_ Kraken2/Bracken database and Bowtie2-indexed host reference genomes.

_Taxonomy files:_ NCBI nodes.dmp and names.dmp.

**Input**

Paired-end FASTQ files (.fastq or .fastq.gz) with matching _R1 and _R2 identifiers. The Python script requires species-level Bracken reports (*.species.bracken.txt) generated by the first script.

**Configuration and Execution**

Before execution, edit the user configuration sections in both scripts to specify the input directory, output directory, reference database locations, thread count and analysis parameters. Stage-specific switches in the Bash script allow individual processing stages to be enabled or disabled.

**Run the scripts sequentially:**

bash step_1_QC_bracken_pipeline.sh

python3 step_2_annotation_and_combination.py

Outputs

Outputs include trimmed FASTQ files, fastp quality-control reports, host-depleted reads, Kraken2 classification reports, Bracken species-level abundance estimates, taxonomically annotated per-sample TSV files and a consolidated combined_species_abundance.csv dataset.

Note: The scripts are configured with example local directory paths. These must be updated before use. The same Kraken2 database and corresponding NCBI taxonomy files should be used for consistent taxonomic annotation.
